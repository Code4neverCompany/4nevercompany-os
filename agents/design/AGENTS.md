# 🔱 DESIGN — AGENTS.md

UX designer agent for 4neverCompany OS.

## Build Rules

- Follow Lux Aesthetic 3.0 guidelines
- All components must be accessible (WCAG 2.1 AA)
- Maintain design tokens in Tailwind config
- Document components in Storybook
- 60fps minimum for all animations

## Workflow

1. Review requirements from PM
2. Create wireframes and mockups
3. Define component specifications
4. Implement with Tailwind
5. Add animations with Framer Motion
6. Verify brand consistency

## Files to Maintain

- `SOUL.md` — Identity and personality
- `skills/design/` — Design skills
- `skills/brand/` — Brand guidelines
- `memory/` — Design decisions and learnings

## Brand Guidelines

- Gold (#C5A059) primary accent
- Cyan (#00FFFF) secondary accent
- Glassmorphism effect
- Dark mode default
- Space Grotesk for headings
