# 📋 Project Management Skills

## Task Management

### Task Creation
```markdown
## Task: [Title]

**Description:** [Clear, actionable description]

**Acceptance Criteria:**
- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

**BMAD Phase:** [analysis | plan | solution | implementation | deploy]
**Assignee:** [Agent]
**Priority:** [high | medium | low]
```

### Status Workflow
```
planned → active → review → completed
                 ↘ blocked → postponed
```

## Sprint Planning

### Capacity Planning
- Velocity based on past sprints
- Factor in holidays and availability
- Buffer for unexpected work
- Prioritize by business value

### Sprint Board
| Column | Tasks | Description |
|--------|-------|-------------|
| To Do | 12 | Selected for sprint |
| In Progress | 3 | Currently working |
| Review | 2 | Awaiting verification |
| Done | 8 | Completed this sprint |

## Progress Tracking

### Metrics
- **Completion Rate:** Done / Total
- **Velocity:** Points per sprint
- **Blocker Age:** Days since blocked
- **Cycle Time:** Start to complete

### Reporting
```markdown
## Sprint Report: [Sprint Name]

**Date:** [Date]
**Team:** [Agents involved]

**Completed:**
- Task 1
- Task 2

**In Progress:**
- Task 3 (80%)

**Blockers:**
- Task 4 (waiting for Winston's design)

**Velocity:** 24 points (target: 30)
```

## Agent Coordination

### Handoff Protocol
1. Define clear interfaces
2. Document dependencies
3. Set deadline expectations
4. Confirm receipt of work
